# 🤝 Contributing to PhotoPost

## 🔀 Branching Strategy
- Everyone has their own branch (e.g., `Mehul`, `Uttam`)
- Task branches are created from personal branches: `User/feat-xyz`
- All merges go → `features` → `dev` → `main`

## 🔧 Commit Messages
Follow this format:
- feat: Add new feature
- fix: Fix a bug
- chore: Non-functional change
- docs: README or documentation changes
  
Example:
```feat: add CLIP-based pose recommender (#1)```

## ✅ Pull Requests
- Always link to the issue (`Closes #X`)
- Fill out PR template
- Wait for code review before merging
